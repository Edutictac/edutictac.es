EduTicTac Link

Connecta el micro:bit amb EduTicTac Blocs i Scratch des de Linux, sense dependre de l'aplicació Scratch Link de Windows/macOS.

Què és

Scratch i maquinari, de manera lliure

Scratch Link és l'aplicació que connecta Scratch amb plaques i robots per Bluetooth, però només s'ofereix per a Windows i macOS. EduTicTac Link és una alternativa lliure per a Linux (Debian, Ubuntu, LliureX i derivats) que connecta el micro:bit —i, de manera experimental, LEGO EV3— amb Scratch i EduTicTac Blocs.

Hi ha dos camins. Tots dos funcionen; el primer no requereix instal·lar res.

Opció A · recomanada

Sense instal·lar res (només navegador)

Amb EduTicTac Blocs i un navegador Chromium (Chrome o Edge), la connexió es fa directament pel navegador (Web Bluetooth). No cal instal·lar cap programa.

  1. Utilitza Chrome o Edge. (A Linux, activa Web Bluetooth a chrome://flags: «Web Bluetooth» i «Experimental Web Platform Features».)
  2. Obre blocs.edutictac.es, prem Afegeix una extensió i tria micro:bit (Bluetooth).
  3. Arrossega el bloc connecta el micro:bit, fes-hi clic i tria la placa al diàleg.
  4. Ja pots fer servir els blocs (botons, inclinació, pantalla, gestos...).

Important: el navegador ha d'estar en el mateix ordinador on està connectat el micro:bit, i la placa ha de tenir el firmware de Scratch (vegeu més avall). Amb Firefox aquest camí no està disponible.

Opció B · avançada

Instal·lar el daemon (Firefox i Chromium)

El daemon edutictac-link funciona en segon pla i connecta el micro:bit amb Scratch o Blocs igual que ho faria Scratch Link. Funciona també amb Firefox i descobreix la placa automàticament. Disponible com a paquet .deb signat.

Ordres del repositori APT 
curl -fsSL https://packages.edutictac.es/edutictac-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/edutictac.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/edutictac.gpg] https://packages.edutictac.es stable main" \
  | sudo tee /etc/apt/sources.list.d/edutictac.list
sudo apt update
sudo apt install edutictac-link

Comprova l'entorn i inicia'l:

Ús 
edutictac-link doctor   # comprova Bluetooth, ports i dependències
edutictac-link          # arranca el daemon

Després, en EduTicTac Blocs o Scratch, afegeix l'extensió micro:bit (la de Scratch) i connecta. El daemon pot quedar-se com a servei d'usuari: systemctl --user enable --now edutictac-link.

El micro:bit necessita el firmware de Scratch

Perquè la placa parli amb Scratch o Blocs cal gravar-li el firmware de Scratch:

  1. Descarrega scratch-microbit-1.2.0.hex.
  2. Connecta el micro:bit per USB: apareixerà una unitat anomenada MICROBIT.
  3. Copia el fitxer .hex a aquesta unitat. La placa es reiniciarà i mostrarà un nom de 5 caràcters (p. ex. petov).

Si veus una cara trista a la matriu, és normal: el firmware la mostra quan està desconnectat. En connectar, canvia.

Qué instala

Un Commons para tu centro

El instalador prepara un despliegue Docker gestionado por systemd. Los servicios funcionan en tu servidor y los datos quedan bajo tu control, sin depender de una plataforma publicitaria.

Commons

Portal, identidad pseudónima, códigos y PIN para organizar actividades.

EduHoot

Cuestionarios y partidas participativas para el aula.

Recursos y Play

Banco de recursos y creación de actividades H5P sencillas.

Instalación

Cómo ponerlo en marcha

  1. Usa un servidor Debian o Ubuntu de 64 bits con Docker y conexión a Internet.
  2. Descarga el instalador y ejecútalo con permisos de administración:
sudo apt install ./edutictac-commons_0.1.1~alpha11_amd64.deb
  1. El instalador genera los secretos, descarga las imágenes y activa el servicio.
  2. Abre la dirección que muestra el instalador y utiliza el código de activación de un solo uso.
  3. Cambia la contraseña inicial de administración y empieza a configurar tu centro.

Funcionamiento

Qué ocurre después

1. Identidad común

El profesorado inicia sesión con una cuenta común en los servicios conectados.

2. Aula sin perfiles

El alumnado entra con un código y un PIN, sin tener que usar correo ni nombre real.

3. Datos locales

Las bases de datos, actividades y copias se guardan en el servidor del centro.

Antes de instalar

  • Servidor Debian/Ubuntu amd64 con al menos 2 GB de RAM libres.
  • Docker Engine, Docker Compose v2 y acceso de salida a Internet.
  • Los puertos 80, 8084, 8086, 8090, 9000 y 9443 deben estar disponibles.
  • Para usarlo desde fuera de la red local, configura HTTPS y un proxy inverso.

EduTicTac Commons

Instal·la en el teu propi servidor un conjunt d’eines educatives lliures, amb identitat comuna, recursos, activitats i taulers per a l’aula.

Descarrega l’instal·lador (.deb) Torna a edutictac.es

Versió actual: 0.1.1-alpha26 · Debian/Ubuntu amd64

Què instal·la

Un Commons per al teu centre

L’instal·lador prepara un desplegament Docker gestionat per systemd. Els serveis funcionen en el teu servidor i les dades queden sota el teu control, sense dependre d’una plataforma publicitària.

Commons

Portal, identitat pseudònima, codis i PIN per a organitzar activitats.

EduHoot

Qüestionaris i partides participatives per a l’aula.

Recursos i Play

Banc de recursos i creació d’activitats H5P senzilles.

Instal·lació

Com posar-lo en marxa

  1. Utilitza un servidor Debian o Ubuntu de 64 bits amb Docker i connexió a Internet.
  2. Descarrega l’instal·lador i executa’l amb permisos d’administració:
Ordre d’instal·lació 
sudo apt install ./edutictac-commons_0.1.1~alpha26_amd64.deb
  1. L’instal·lador genera els secrets, descarrega les imatges i activa el servei.
  2. Obri l’adreça que mostra l’instal·lador i utilitza el codi d’activació d’un sol ús.
  3. Canvia la contrasenya inicial d’administració i comença a configurar el teu centre.

Descàrrega i actualitzacions

Descarrega 0.1.1-alpha26 (.deb) Consulta el codi font

Afig el repositori APT

Així podràs instal·lar i actualitzar Commons amb les actualitzacions signades del projecte:

Ordres del repositori APT 
curl -fsSL https://packages.edutictac.es/edutictac-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/edutictac.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/edutictac.gpg] https://packages.edutictac.es stable main" \
  | sudo tee /etc/apt/sources.list.d/edutictac.list
sudo apt update
sudo apt install edutictac-commons

En instal·lacions posteriors, actualitza amb sudo apt update && sudo apt install --only-upgrade edutictac-commons.

Funcionament

Què passa després

1. Identitat comuna

El professorat inicia sessió amb un compte comú en els serveis connectats.

2. Aula sense perfils

L’alumnat entra amb un codi i un PIN, sense haver d’utilitzar correu ni nom real.

3. Dades locals

Les bases de dades, activitats i còpies es guarden en el servidor del centre.

Abans d’instal·lar

  • Servidor Debian/Ubuntu amd64 amb almenys 2 GB de RAM lliures.
  • Docker Engine, Docker Compose v2 i accés d’eixida a Internet.
  • Els ports 80, 8084, 8086, 8090, 9000 i 9443 han d’estar disponibles.
  • Per a utilitzar-lo fora de la xarxa local, configura HTTPS i un proxy invers.

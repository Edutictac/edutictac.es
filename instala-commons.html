Instal·lació autònoma

EduTicTac Commons

Instal·la al teu propi servidor un conjunt d’eines educatives lliures, amb identitat comuna, recursos, activitats i taulers per a l’aula.

Manual pas a pas Guia d’instal·lació (PDF)

Versió actual: 0.1.1-beta6.2 · LliureX · Debian/Ubuntu amd64

Què instal·la

Un Commons per al teu centre

L’instal·lador prepara un desplegament Docker gestionat per systemd. Els serveis funcionen al teu servidor i les dades queden sota el teu control, sense dependre d’una plataforma publicitària.

Commons

Aules, codis i PIN, Rebost d’imatges, fitxers compartits i entregues privades de l’alumnat.

EduHoot

Qüestionaris i partides participatives per a l’aula.

Recursos i Play

Banc de recursos i creació d’activitats H5P senzilles.

Blocs

Programació amb blocs, personatges i escenaris del Rebost.

Llibres

Contes il·lustrats i còmics, amb enviament al docent per a revisar-los.

Quiosc per a LliureX

Activitats supervisades amb Epoptes en l’ordinador del professorat.

Abans d’instal·lar

  • Equip amd64 amb LliureX, Debian o Ubuntu. Provat en LliureX amb 5 GB de RAM assignats al professor; el consum depén de les ferramentes activades.
  • Docker Engine, Docker Compose v2 i accés de sortida a Internet.
  • Nucli: ports 8082, 8091 (local), 9000 i 9443. Mòduls opcionals: 8084, 8086, 8090 i 8098.
  • Per a utilitzar-lo fora de la xarxa local, configura HTTPS i un proxy invers.

Manual d’instal·lació

Per a la persona que prepara l’ordinador del centre. L’alumnat no ha d’instal·lar Commons: hi accedeix des del navegador.

  1. 1. Afig el repositori oficial

    Obre una terminal en l’ordinador que serà el servidor. Afig el repositori signat d’EduTicTac amb les ordres que trobaràs més avall. Només cal fer-ho la primera vegada.

  2. 2. Instal·la Commons amb APT

    Amb el repositori afegit, executa esta ordre, introdueix la contrasenya d’administració de l’ordinador i espera que acabi. Es descarregaran els serveis; pot tardar uns minuts.

    Ordre d’instal·lació 
    sudo apt install edutictac-commons

  3. 3. Guarda el codi i reinicia

    Al final apareix un codi d’activació. Guarda’l sense compartir-lo i reinicia l’ordinador abans d’activar aplicacions o fer còpies des del panell.

  4. 4. Obre Commons

    Obre EduTicTac Commons des del menú d’aplicacions. La instal·lació de la beta6.2 mostra l’adreça mDNS i la IP, i l’accés directe inclou el port; si edutictac.local no es resol, usa la IP que apareix a la instal·lació.

  5. 5. Activa la instal·lació

    Introdueix el codi que has guardat. La pantalla mostra les credencials inicials d’administració: guarda-les de manera segura i canvia la contrasenya des de l’enllaç al panell d’accés. Només cal activar una vegada.

  6. 6. Tria les aplicacions

    Entra a Administració amb el compte inicial. Activa les eines que necessites i espera que acabi: Play, EduHoot, Banc de recursos, Blocs, Llibres o Quiosc. El nucli ja inclou les aules, Rebost i els fitxers d’aula.

Com accedir-hi

Amb la beta6.2, la instal·lació mostra l’adreça mDNS i la IP del servidor, i l’accés directe inclou el port. Si edutictac.local no es resol, entra per la IP.

  • Menú d’aplicacions: «EduTicTac Commons». La beta6.2 també crea una icona a l’escriptori de qui instal·la.
  • Adreça habitual: http://edutictac.local:8082/. Si el port és el 80, sense :8082.
  • Si edutictac.local no resol, usa la IP del servidor: http://192.168.x.x:8082/. Per al login docent per IP, cal configurar EDUTICTAC_PUBLIC_HOST.

Quiosc necessita un servidor Epoptes compatible. No cal activar-lo per utilitzar les altres aplicacions.

Comprova que funciona

Entra com a docent i crea una aula de prova. Genera una credencial d’alumnat i prova-la des d’un altre navegador o equip de la mateixa xarxa amb el codi i el PIN. Obre una aplicació i comparteix un fitxer amb l’aula.

Mantén el servidor encès mentre s’utilitza Commons. L’alumnat entra amb codi i PIN; no necessita un compte docent.

Afegeix el repositori APT

Així podràs instal·lar i actualitzar Commons amb les actualitzacions signades del projecte:

Ordres del repositori APT 
curl -fsSL https://packages.edutictac.es/edutictac-archive-keyring.gpg \
  | sudo gpg --batch --yes --dearmor \
    -o /usr/share/keyrings/edutictac.gpg
echo "deb [signed-by=/usr/share/keyrings/edutictac.gpg]" \
  "https://packages.edutictac.es stable main" \
  | sudo tee /etc/apt/sources.list.d/edutictac.list
sudo apt update
sudo apt install edutictac-commons

Per a actualitzar una instal·lació anterior, instal·la el paquet nou amb sudo apt update && sudo apt install --only-upgrade edutictac-commons. Abans d’actualitzar les imatges, configura el xifratge de les còpies i guarda la clau privada fora del servidor. Després, actualitza les imatges des d’Administració. Es conserven els comptes, les aules i els treballs del servidor; l’actualitzador fa una còpia abans del canvi.

Funcionament

Què passa després

1. Identitat comuna

El professorat inicia sessió amb un compte comú en els serveis connectats.

2. Aula sense perfils

L’alumnat entra amb un codi i un PIN, sense haver d’utilitzar correu ni nom real.

3. Dades locals

Les bases de dades, activitats i còpies es guarden en el servidor del centre.

Si alguna cosa no respon

L’accés encara no apareix

El servei d’accés pot tardar més que el portal a preparar-se. Espera una mica i torna a provar. Si encara s’està instal·lant, deixa que acabi la descàrrega.

No s’obre des d’un altre equip

Comprova que tots dos equips siguin a la mateixa xarxa i utilitza l’adreça que ha indicat l’instal·lador. En LliureX, Commons sol utilitzar el port 8082. Si el nom no es resol, consulta el responsable del centre.

Falta el codi o la contrasenya inicial

Demana ajuda a qui va instal·lar el servidor. No reinstal·lis ni esborris dades per recuperar l’accés.

Les còpies del servidor no inclouen els projectes guardats només al navegador. Descarrega també els llibres i projectes que vulguis conservar, i guarda una còpia del servidor fora de l’equip.
